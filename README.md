# Love Letter

[Открыть письмо](https://grinderek.github.io/for-my-beloved/)

Письмо для Лизы: конверт с печатью, наши записки и приглашение на свидание.

## Где что менять

- `src/index.html` - весь текст, карточки и варианты свидания.
- `src/style.css` - цвета, шрифты, конверт, анимации и мобильная верстка.
- `src/app.js` - открытие конверта, выбор свидания и сообщение в Telegram. Имя получателя задается в `telegramUsername`.
- `love-letter-preview.png` - обложка ссылки в Telegram.

У варианта свидания нужно менять и надпись кнопки, и ее `data-choice`: значение атрибута попадет в ответ. Текст сообщения находится в функции `confirmDate`.

## Локальный просмотр

Нужны Node.js 20 или новее и npm.

```sh
npm ci
npm run dev
```

Страница откроется по адресу `http://127.0.0.1:4173`. После правок достаточно обновить вкладку. Можно также открыть `src/index.html` прямо в браузере.

```sh
npm run format
npm run check
npm run build
```

## Сборка и публикация

`npm run build` собирает HTML, CSS и JavaScript в один минифицированный `index.html` в корне. Его читает GitHub Pages из ветки `main`, папки `/`.

После правок в `src/` запусти сборку и закоммить измененные исходники вместе с корневым `index.html`. Одного изменения исходников для обновления сайта недостаточно.

Сборка также создает `Лизе.html` - отдельный файл, который можно открыть без сервера, и локальные копии в `dist/` и `github-pages/`. Эти файлы генерируются, редактировать их вручную не нужно.

Шрифты загружаются из Google Fonts. Без интернета используются системные шрифты. Блок свидания скрывается при обычной печати браузером. Кнопки печати на странице нет.
